# Docker dev environment: app + Postgres/PostGIS + dev tools

The Docker dev environment containerizes the full stack: the Node app (with hot reload via ts-node-dev, source mounted as a volume), a `postgis/postgis` database service, and convenience dev services — a database admin UI (Adminer) and any future dev tooling (e.g. Mailhog for email-flow testing). One `docker compose up` brings up the entire environment. We chose full containerization over the lighter "db-only containerized, app on host" pattern because reproducibility and convenience matter for this project: no per-developer Node version drift, no manual PostGIS extension setup, and a database admin UI available out of the box. The trade-off is slightly slower hot reload (container volume-sync and rebuild-on-dependency-change friction) and more moving parts, accepted for a self-contained, one-command dev environment. An `.nvmrc` is included for developers who prefer running the app on the host.

# Multilingual catalog with a locale-neutral wire format

Albums and Stickers carry canonical catalog entries with per-locale display names, seeded with English and Spanish at launch; French and Portuguese arrive later as pure data — locales are rows, not columns, so no schema change. Catalog search matches across all language variants (unaccent + trigram), so a Spanish query finds an English-named album and vice versa; otherwise Spanish-speaking users would re-contribute existing albums under Spanish names, multiplying 0004's duplicate-fragmentation risk. The wire format stays locale-neutral: REST errors and socket events carry codes plus data — ids, minor-unit amounts with currency codes, ISO 8601 timestamps — never English prose; clients render all user-facing wording from the User's preferred locale. User-generated content (Chat Messages, Listing descriptions) is stored exactly as authored and never translated server-side; UI translation is entirely front-end. Trade-offs: per-locale translation maintenance for a user-contributed catalog, and a growing operator canonicalization burden as locales accumulate.

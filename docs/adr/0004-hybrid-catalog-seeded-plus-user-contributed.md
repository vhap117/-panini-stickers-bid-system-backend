# Hybrid catalog: seeded albums plus user-contributed entries

The Album/Sticker catalog is built from a small curated seed (one or two popular albums loaded by the operator before launch) plus user-contributed entries for albums that don't yet exist. Users pick from existing catalog data when creating a draft; if their album or sticker isn't present, they can add it. We chose this over a fully pre-seeded catalog (a multi-month data-sourcing project across Panini's enormous, multilingual roster) and over fully user-generated (which produces duplicate and inconsistent entries — "Qatar 2022" vs "World Cup 2022 Qatar" — that break search and feed grouping). The trade-off is a future need for dedup/merge tooling and admin canonicalization of user-added albums, accepted in exchange for shipping without a complete catalog project.
